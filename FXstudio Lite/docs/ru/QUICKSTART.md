# Быстрый старт · VoxelMotion 2.13.0

## Без PowerShell

Откройте папку `FXstudio Lite/resources/app/dist` и запустите:

- `VoxelMotion-2.13.0-Portable.exe` — сразу работать без установки.
- `VoxelMotion-2.13.0-Setup.exe` — установить с ярлыком.

Перед обновлением закройте старое окно. Node.js для этих EXE не нужен.

## Что попробовать

1. Откройте эффект и измените параметр. Вверху появится время автосохранения.
2. Закройте и снова откройте приложение. Нажмите «Продолжить».
3. Создайте подборку и добавьте эффект через `⋯` на карточке.
4. В редакторе попробуйте `Ctrl+D` и кнопку слоёв для точных координат.
5. В экспорте выберите пресет Shorts, TikTok или YouTube. Подтверждение появится после сохранения файла.

Выберите звук в редакторе эффекта: короткий звук из каталога или свой файл. MP4 и WebM сохраняются со звуком.

## Запуск исходников

При установленных зависимостях:

```powershell
cd 'C:\.projects\FXstudio-Lite-Clone\FXstudio Lite\resources\app'
npm start
```

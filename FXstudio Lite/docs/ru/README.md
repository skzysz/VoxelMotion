# VoxelMotion 2.13.1

Каталог эффектов Minecraft для Windows x64. Все 188 эффектов доступны без подписки.

## Запуск без терминала

Готовые файлы находятся в `resources/app/dist/`:

- `VoxelMotion-2.13.1-Setup.exe` — установщик с выбором папки, ярлыками рабочего стола и меню «Пуск».
- `VoxelMotion-2.13.1-Portable.exe` — запуск без установки.
- `win-unpacked/VoxelMotion.exe` — распакованная самостоятельная версия; переносите всю папку `win-unpacked` целиком.

Node.js для готовых версий не требуется. Перед запуском обновления закройте прежнее окно приложения. Все эти версии используют прежний профиль данных FXstudio Lite; удаление программы через установщик не удаляет пользовательские данные. Установщик и EXE собраны без сертификата цифровой подписи.

## Новые функции

### Звук эффекта

В редакторе нажмите кнопку звука или строку «Звук эффекта». Доступны короткие звуки без интернета, поиск по каталогу Minecraft и импорт собственного звукового файла (до 50 МБ). Настраиваются включение, громкость, задержка и повтор до конца эффекта. Можно прослушать звук отдельно или вместе с эффектом, а также скачать исходный звук.

MP4 получает дорожку AAC, WebM — Opus; прозрачность WebM сохраняется. GIF, PNG и PNG-кадры остаются без звука. Выбранный звук сохраняется в библиотеке профиля, его настройки — в черновике и варианте эффекта. Отдельного звукового таймлайна нет.

### Обновления из GitHub

Кнопка «Обновления» находится в шапке каталога и в настройках. По умолчанию проверка выполняется при запуске и каждые 6 часов. В установленной через Setup версии найденное обновление скачивается автоматически. Установка и перезапуск выполняются только по кнопке, после сохранения черновика; во время экспорта установка запрещена. Автоматическую проверку можно выключить.

Portable и запуск исходников проверяют новую версию и открывают страницу релиза. Автоматическая установка доступна версии из Setup. Для перехода с 2.12.1 необходимо один раз установить Setup 2.13.1 вручную, поскольку в 2.12.1 модуля обновлений ещё не было. Файлы проверяются модулем electron-updater по SHA-512; сборки по-прежнему не имеют цифровой подписи издателя.

### Автосохранение и восстановление

Изменения обычного редактора эффекта, сцены и слоёв сохраняются после короткой паузы. В шапке показано состояние сохранения; `Ctrl+S` сохраняет немедленно. При обычном закрытии записывается финальный снимок. После повторного запуска кнопка «Продолжить» в каталоге или разделе «Проекты» возвращает черновик, слои, настройки сцены и положение воспроизведения.

Файлы `recovery/draft.json` и `recovery/draft.previous.json` находятся в профиле приложения. Запись выполняется через временный файл; при повреждении последнего снимка доступна предыдущая копия. Ошибка записи видна в интерфейсе, доступна повторная попытка; окно не закрывается молча при неудаче финального сохранения. Сохраняется один последний рабочий черновик. При аварии могут потеряться изменения после последнего завершённого автосохранения. Импортированные изображения остаются в библиотеке того же профиля.

### Каталог

«Недавние», избранное, личные подборки и поиск по названиям и тегам. Пример поиска категории: `#trans`. Меню `⋯` на карточке добавляет эффект в подборку. Наведение мыши запускает живой предпросмотр, если в системе не включено уменьшение анимации. При уходе с карточки предпросмотр останавливается.

### Редактор

Кнопка слоёв в шапке открывает точные координаты X/Y, масштаб и поворот, выравнивание и дублирование. `Ctrl+D` копирует активный слой; `Alt+стрелки` сдвигают его на 1 пиксель, `Alt+Shift+стрелки` — на 10. Сетка третей и центра включается в этом же окне. Привязки к направляющим доступны через существующий магнит предпросмотра.

Кнопка истории открывает последние действия и отмену/повтор. `Ctrl+Z` и `Ctrl+Shift+Z` используют общую историю редактора (до 60 состояний). Копирование относится к целому слою, включая содержащиеся в нём объекты.

### Пресеты

В экспорте доступны YouTube Shorts, TikTok/Reels, горизонтальный YouTube, прозрачное видео и GIF-стикер. Текущие настройки можно сохранить как свой пресет. Кнопка вариантов эффекта в шапке сохраняет и применяет свои композиции с параметрами, слоями и сценой.

### Экспорт

Проверены PNG, MP4, WebM с альфа-каналом, GIF и ZIP с PNG-кадрами. Прогресс, отмена и обработка ошибок доступны в окне экспорта; подтверждение сохранения приходит после завершения записи файла. Папка выбирается в настройках; по умолчанию используются системные «Загрузки». Существующие файлы не перезаписываются — к имени добавляется номер.

К эффекту можно привязать один звук; MP4 и WebM экспортируются со звуком. Звук выбирается в редакторе эффекта: громкость, задержка и повтор без отдельного таймлайна. MP4 не поддерживает прозрачность в этой программе; для неё используйте WebM, PNG или PNG-кадры.

## Разработка и проверка

Для запуска исходников требуется Node.js 22.12+:

```powershell
cd 'C:\.projects\FXstudio-Lite-Clone\FXstudio Lite\resources\app'
npm ci
npm start
```

Команды проверки и сборки:

```powershell
npm test
npm run verify:recovery
npm run verify:export
npm run verify:workspace
npm run verify:sound-updates
npm run dist
npm run verify:update-download
node verify-packaged.cjs
node verify-packaged.cjs 'dist/VoxelMotion-2.13.1-Portable.exe'
```

Проверки интерфейса запускают и закрывают собственный экземпляр Electron с отдельным профилем `.qa-recovery-profile`; аварийное завершение и повреждение файлов моделируются только там. Не запускайте эти сценарии одновременно: они используют один локальный порт 9555. Скриншоты и отчёты находятся в `docs/ru/screenshots/recovery`, `export`, `workspace` и `packaged`.

## Основные файлы

- `resources/app/main.js`, `preload.js` — окно, безопасный IPC-мост, загрузки и настройки.
- `resources/app/recovery-store.cjs` — проверка и атомарная запись черновиков.
- `resources/app/www/index.html` — исходный редактор эффектов.
- `resources/app/www/desktop/recovery.js` — автосохранение и восстановление.
- `resources/app/www/desktop/catalog.js` — каталог и подборки.
- `resources/app/www/desktop/editor-tools.js` — инструменты слоёв и история.
- `resources/app/www/desktop/export-tools.js` — пресеты и обратная связь экспорта.
- `resources/app/electron-builder.yml` — сборка Windows EXE и установщика NSIS.
- `resources/app/audio-export.cjs` — добавление звука через FFmpeg, прогресс и отмена.
- `resources/app/update-service.cjs` — проверка релизов, скачивание и установка обновлений.
- `resources/app/www/desktop/effect-sound.js`, `updates.js` — настройки звука и обновлений.

FFmpeg включён в установщик. Его оригинальная лицензия и сведения о сборке находятся в `resources/ffmpeg`; подробности — в `resources/app/THIRD_PARTY.md` исходного проекта.

## Если приложение не открывается

Повторный запуск показывает уже открытое окно. Если встречается отказ доступа к кэшу, проверьте, не остался ли фоновый экземпляр с тем же профилем. Не удаляйте профиль целиком: он содержит проекты и библиотеку.

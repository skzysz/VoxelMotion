# VoxelMotion

Каталог эффектов Minecraft с настройками и звуком для Windows x64. Версия **2.13.1**.

В 2.13.1 обновлены карточки каталога, поиск, категории и боковое меню. Исправлены подпись и значок кнопки «Обновления» и отображение в компактных окнах.

188 эффектов, сцены и слои, автосохранение с восстановлением, личные подборки, варианты эффектов и пресеты экспорта. Форматы: MP4, прозрачный WebM, GIF, PNG и ZIP с PNG-кадрами. К эффекту можно привязать один звук; MP4 и WebM экспортируются со звуком.

## Запуск

В 2.13.0 добавлены **звук эффекта** и **обновления из GitHub Releases**. Это каталог эффектов с настройками, без монтажа звуковых дорожек и отдельного таймлайна.

Для перехода с 2.12.1 один раз установите новый Setup: в старой версии ещё не было модуля обновлений. В дальнейшем установленная программа проверяет версии, скачивает обновление и предлагает кнопку установки с перезапуском. Portable проверяет версии и открывает страницу скачивания.

Скачать готовую программу: [GitHub Releases](https://github.com/skzysz/VoxelMotion/releases).

Готовые приложения находятся в `FXstudio Lite/resources/app/dist/`:

- `VoxelMotion-2.13.1-Portable.exe` — без установки и Node.js.
- `VoxelMotion-2.13.1-Setup.exe` — установка с ярлыками.

В опубликованном репозитории готовые EXE следует скачивать со страницы **Releases**, поскольку папка `dist` исключена из Git.

## Разработка

Требуется Node.js 22.12+.

```powershell
cd 'FXstudio Lite/resources/app'
npm ci
npm start
```

```powershell
npm test
npm run verify:recovery
npm run verify:export
npm run verify:workspace
npm run dist
```

Проверки интерфейса запускайте последовательно: они используют общий отдельный тестовый профиль и локальный порт 9555.
